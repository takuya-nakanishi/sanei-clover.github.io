Agent Workspace

AIエージェントから Google スプレッドシート・ドキュメント・スライドを安全に読み書きするための、株式会社サンエイクローバーの社内ツールです。

Agent Workspace とは

Agent Workspace は、株式会社サンエイクローバー（以下「当社」）が開発・運用するアプリケーションです。Anthropic 社の AI アシスタント「Claude」から、Model Context Protocol（MCP）を通じて Google が提供する公式 MCP サーバー（Google スプレッドシート / Google ドキュメント / Google スライド）に接続し、利用者が指定した Google のファイルを読み取り・編集します。

利用者は当社の役職員および当社が業務を委託する担当者に限られ、一般公開・第三者への提供は行っていません。

できること

  • Google スプレッドシートのセル値の読み取り、値・数式の更新、行や列の挿入
  • Google ドキュメントの本文の読み取りと編集
  • Google スライドのプレゼンテーションの読み取りと編集
  • 上記を AI アシスタントとの対話から実行し、財務管理表の更新や議事録・資料作成などの業務を省力化する

Google アカウントのデータへのアクセスについて

Agent Workspace は、利用者が Google アカウントで明示的に許可した場合にのみ、次の権限（OAuth スコープ）を使用します。権限はいずれも「利用者が指定したファイルを、利用者の指示に従って読み書きする」目的に限って使用します。

権限利用目的
Google スプレッドシートの閲覧・編集利用者が指定したスプレッドシートの値・数式を読み取り、指示に従って更新するため
Google ドキュメントの閲覧・編集利用者が指定したドキュメントの本文を読み取り、指示に従って編集するため
Google スライドの閲覧・編集利用者が指定したプレゼンテーションを読み取り、指示に従って編集するため

当社は、これらの権限で取得したデータを、利用者の指示した処理以外の目的（広告、販売、他サービスへの転用、AI モデルの学習など）には使用しません。詳細は「プライバシーポリシー」の「Google ユーザーデータの取り扱い（Agent Workspace）」をご覧ください。

アクセスの取り消し

利用者はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から Agent Workspace のアクセス権を取り消せます。取り消し後、Agent Workspace は利用者の Google データにアクセスできなくなります。

Summary (English)

Agent Workspace is an internal application developed and operated by Sanei Clover Co., Ltd. It connects Anthropic's Claude AI assistant to Google's official MCP servers for Google Sheets, Google Docs and Google Slides, so that authorized staff can read and edit the Google files they specify through natural-language instructions. Agent Workspace requests access to Google Sheets, Google Docs and Google Slides only after the user explicitly grants permission, and uses that access solely to read and edit the files the user designates. We do not sell Google user data, use it for advertising, or use it to train AI models. See our Privacy Policy (https://sanei-clover.com/privacy.html#google-user-data) for details. Users can revoke access at any time at https://myaccount.google.com/permissions.
