# J0003 AIO の土台: Organization/Person/WebSite の JSON-LD と llms.txt を置く

AIO(AI 検索最適化。ChatGPT・Perplexity・Google の AI による概要に自社を正しく引用させる施策)の最初の一手。
半日で終わり、以後に足すコンテンツ全部に効くので、FAQ・事例(J0006)より先にやる。

## やること

- `index.html` の `<head>` に JSON-LD を置く
  - `Organization`: 名前(`株式会社サンエイクローバー`)・`alternateName`(`Sanei Clover`・`SANEi CLOVER`)・`url`・`logo`・`foundingDate`(2024-12-17)・`founder`(中西 拓也。プロフィール頁の Person を `@id` で指す)・`address`(PostalAddress。会社概要の節と同じ字)・`telephone`(+81-3-6876-4989)・`sameAs`(note `https://note.com/sanei_clover`)・`contactPoint`・`knowsAbout`(生成AI / Salesforce / システム開発)
  - `WebSite`: 名前と URL
  - 事業 3 つは `Organization` の `hasOfferCatalog` か `Service` で表す(会社概要と事業内容の節に書いてある字をそのまま使う。誇張しない)
- `profiles/takuya-nakanishi/index.html` に `Person` の JSON-LD(`@id` を固定し、`worksFor` で Organization を指す)
- ルートに `llms.txt`(llmstxt.org の形。H1・引用・主要ページへのリンクと一行説明)。Jekyll が配信するよう front matter は付けない(そのまま静的に配る)
- `robots.txt` は全許可のまま。変えない

## 制約

- 値は本文(会社概要・事業内容・プロフィール)に書いてある事実だけ。本文に無い数字・実績・肩書を足さない
- 会社名・住所・電話は AGENTS.md の「会社概要」と一致させる
- JSON-LD は Jekyll の Liquid と衝突しない(`{{`・`{%` を含まない)
- 構造化データの確認は Google の Rich Results Test か schema.org validator で人が確かめる(Codex は JSON として parse できることまで確かめる)
