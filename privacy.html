プライバシーポリシーPrivacy Policy

個人情報保護に関する当社の方針。法令を遵守し、細心の注意を払って情報をお預かりします。

Last updated · 2026.09.08

株式会社サンエイクローバー（以下「当社」）は、お客様の個人情報保護の重要性について認識し、個人情報保護に関する法令を遵守するとともに、細心の注意を払ってお客様の個人情報を保護します。

個人情報の収集について

当社は、お問い合わせフォームのご利用、またはその他当社サービスを通じて、お客様の氏名、メールアドレス等の個人情報を取得することがあります。これらの情報は、ご本人の同意なく、利用目的の範囲を超えて収集することはありません。

個人情報の利用目的

収集した個人情報は、以下の目的で利用します。

  • お客様からのお問い合わせへの対応
  • 当社サービスの提供、運営のため
  • 当社サービスに関する情報提供のため
  • サービスの改善、新サービスの開発のため

Google Analyticsの利用について

当社のウェブサイトでは、サイト利用状況の分析のためにGoogle Analyticsを利用しています。Google Analyticsは、クッキー（Cookie）を利用してウェブサイトの閲覧情報を収集します。この情報は匿名で収集されており、個人を特定するものではありません。

Google Analyticsのデータ収集、処理の仕組みについては、Googleのウェブサイトをご確認ください。

第三者への提供について

当社は、法令に基づく場合等正当な理由によらない限り、事前にご本人の同意を得ることなく、個人情報を第三者に開示・提供することはありません。

Google ユーザーデータの取り扱い（Agent Workspace）

当社が運用するアプリケーション「Agent Workspace」（https://sanei-clover.com/products/agent-workspace/）は、Google の OAuth 認可を通じて、利用者の Google アカウントのデータにアクセスします。本節では、その取り扱いを定めます。

（1）取得するデータ
利用者が明示的に許可した範囲で、Google スプレッドシート・Google ドキュメント・Google スライドのうち、利用者が指定したファイルの内容（セル値・数式・本文・スライド内容）およびファイルのメタデータ（タイトル等）を取得します。利用者の Google アカウントのメールアドレス等の基本情報は、認可の識別に必要な範囲でのみ取り扱います。

（2）利用目的
利用者が AI アシスタントに指示した処理（指定ファイルの読み取り・更新）を実行する目的に限って利用します。広告、販売、利用者が指示していない他の目的、および AI モデルの学習には使用しません。

（3）データの保存
当社は、取得した Google ユーザーデータを当社のサーバーに保存しません。データは処理の都度、Google の MCP サーバーと利用者が使用する AI アシスタント（Anthropic 社の Claude）との間で送受信されます。Claude 側でのデータの保持については、Anthropic 社のプライバシーポリシーに従います。

（4）第三者への共有
利用者の指示を実行するために必要な範囲で、Google ユーザーデータは Anthropic 社の Claude サービスへ送信されます。それ以外の第三者への提供・販売は行いません。ただし、法令に基づく開示要請には応じることがあります。

（5）アクセスの取り消しとデータの削除
利用者は Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも Agent Workspace のアクセス権を取り消せます。当社は Google ユーザーデータを保存しないため、取り消しにより当社側に残るデータはありません。

（6）Google API サービスのユーザーデータに関するポリシーの遵守
Agent Workspace による Google API から取得した情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシーの「限定的な使用（Limited Use）」の要件を含め、同ポリシーに準拠します。
