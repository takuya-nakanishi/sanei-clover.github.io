Works アプリのプライバシーポリシーPrivacy Policy

Android アプリ「Works」が、利用者の情報をどこに保存し、どこへ送るかを定めます。

Last updated · 2026.10.07

株式会社サンエイクローバー（以下「当社」）は、当社が提供する Android アプリ「Works」（以下「本アプリ」）について、利用者の情報の取り扱いを以下のとおり定めます。本アプリは、顧客・商談・タスクなどを管理するサービス「Works」のサーバに接続して使うアプリです。

情報の行き先

本アプリが通信する相手は、利用者がアプリに入力した Works のサーバだけです。サーバは利用者が所属する組織（勤務先など）が運用しており、サーバに保存されるデータの取り扱いは、そのサーバを運用する組織の方針に従います。当社がそのサーバを運用している場合を除き、本アプリから当社へ利用者の情報が送られることはありません。

端末に保存する情報

  • 接続先のサーバの URL
  • ログインの状態を保つための情報（サーバが発行するトークン）。端末の Android Keystore の鍵で暗号化して保存します
  • 表示を速くし、通信できない場所でも使えるようにするための、サーバのデータの写し
  • まだサーバへ送っていない変更

本アプリはパスワードを扱いません。ログインは、ブラウザで開くサーバのログイン画面で行います。

サーバへ送る情報

利用者がアプリで行った操作の内容（記録の作成・変更・削除、AI チャットへの入力など）を、接続先のサーバへ送ります。通信は暗号化（HTTPS）されます。AI による処理を含め、サーバ側での取り扱いは、サーバを運用する組織の方針に従います。

第三者への提供・広告・解析

本アプリは、広告を表示する仕組みや、利用状況を解析・追跡する仕組み（外部の SDK）を含みません。本アプリから第三者へ利用者の情報を送ることはありません。

使う権限

通信のための権限（インターネットへの接続、通信状態の確認）と、まだ送っていない変更を通信できるようになったときに送るための権限だけを使います。カメラ・マイク・位置情報・連絡先・写真には触れません。

データの削除

  • ログアウトすると、そのサーバ・その利用者について端末に保存した情報（データの写し・未送信の変更・トークン）を消し、サーバ側のログインの許可も取り消します
  • アプリをアンインストールすると、端末に保存した情報はすべて消えます
  • 端末のバックアップや機種変更の移行に、本アプリの情報は含めません
  • サーバに保存されたデータやアカウントの削除は、サーバを運用する組織へ依頼してください。本アプリの中でアカウントを作ることはできません

本ポリシーの変更について

本ポリシーの内容は、本アプリの機能の変更や法令改正等により、必要に応じて変更する場合がございます。変更後のプライバシーポリシーは、本ウェブサイトに掲載した時点より効力を生じるものとします。当社のウェブサイト全般の取り扱いは、当社のプライバシーポリシーをご覧ください。

Summary in English

This policy describes how the Android app "Works" (the "App"), provided by SANEi CLOVER, INC., handles user information.

  • The App communicates only with the Works server whose URL the user enters. That server is operated by the user's organization, and data stored on it is handled under that organization's policies. Unless SANEi CLOVER, INC. operates that server, the App sends no user information to SANEi CLOVER, INC.
  • The App stores on the device: the server URL, sign-in tokens issued by the server (encrypted with an Android Keystore key), a cached copy of the server data, and changes not yet sent. The App does not handle passwords; users sign in on the server's sign-in page in a browser.
  • The App sends the user's operations (creating, editing and deleting records, input to the AI chat, etc.) to the server over HTTPS.
  • The App contains no advertising or analytics SDKs and shares no information with third parties.
  • Signing out deletes the data stored for that server and user and revokes the sign-in grant. Uninstalling deletes all data the App stored. App data is excluded from device backups and transfers. Accounts are managed by the server operator and cannot be created in the App.
  • Contact: SANEi CLOVER, INC., tnakanishi@sanei-clover.com
